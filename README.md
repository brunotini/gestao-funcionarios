# Gestão de Funcionários

Projeto acadêmico da disciplina de Software Product — AC1 (Front-end).

## Sobre o projeto

Sistema simples para cadastro e listagem de funcionários, desenvolvido com:

- **Front-end:** HTML5, CSS3 e JavaScript
- **Back-end:** Python com Flask
- **Banco de dados:** SQLite

## Funcionalidades

- Cadastro de funcionários (nome, tempo de empresa, freelancer)
- Listagem de funcionários cadastrados
- Contadores no topo (total, freelancers e fixos)
